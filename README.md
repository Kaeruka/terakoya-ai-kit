# 寺子屋AI 制作キット

会話しながら自分の「マイツール」を作り、**セミナーまるっと用意くん**で告知文・LP・画像まで用意するための共通仕様です。

## はじめかた

1. ChatGPTのワークで、Sitesを使える状態にします。
2. [マイツール作成の短い指示](prompts/start-mytools.txt)を貼り付けます。AIが仕様を読めない場合は[完全版](prompts/mytools.txt)と[共通告知仕様](docs/announcements.md)を渡します。
3. 制作が始まったら、事業名と事業内容に答えます。回答前に作れる部分から制作を進め、回答は同じサイトへ反映する設計です。
4. [セミナーまるっと用意くんの作成指示](prompts/start-seminar.txt)を使い、完成したツールを[マイツールへ登録](docs/registration.md)します。
5. [制作手順](docs/production-flow.md)に沿って、告知文・LP・画像を作ります。

このキットを参照しただけで、サイトの作成・公開やSNS投稿が完了するわけではありません。作成されたサイトと保存状態を確認して利用を始めてください。

## できあがるもの

- 本人専用のマイツール：事業プロフィールとツール一覧。
- 本人専用のセミナーまるっと用意くん：素材を整理し、ChatGPTへ渡す指示を作り、返ってきた結果を保存。
- お客様向けの告知LPと、チラシ・SNSに使う画像。
- マイツール左下に表示する、寺子屋AIの共通告知。

本人専用の情報は公開リポジトリへ入れません。公開LPには掲載を決めた情報だけを使います。

## 仕様の更新

初回制作は公開リポジトリの仕様を参照します。運営が検証した版を配布するときは、ブランチ名ではなくタグまたはコミットを固定したURLに置き換えてください。共通告知だけは更新用のJSONを実行時に読みます。既存サイトのプログラムがGitHub更新だけで自動更新される仕組みではありません。

本資料は仕様と手順です。各環境での動作確認結果は、実施日・対象版・実際の結果を分けて記録してください。
