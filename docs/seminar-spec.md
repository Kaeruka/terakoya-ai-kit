# セミナーまるっと用意くん

## 目的と画面

告知素材を一度入力し、ChatGPTで文章・LP・画像を作るための指示と結果をまとめる本人専用ツールです。「告知を作る」「事業情報」「設定」の3画面を基本にします。名称はセミナーまるっと用意くんに統一します。

初版のサイト内部から生成AI APIを呼びません。APIキー入力、SNS自動投稿、決済、CRMを追加しません。文章を保存した状態と、LPや画像が完成した状態を区別します。

## 入力と保存

告知素材は100KB以下のtxt、貼り付け、直接入力を受け付けます。直接入力は「何を告知したいですか」必須、「詳しい情報」「文体・必ず伝えたいこと」任意。事業情報はマイツールからコピーして保存します。初期状態に架空の本人情報を入れません。

日時、価格、定員、会場、申込URLが未定なら未定として保持し、生成依頼に創作禁止を含めます。架空素材で試す場合はデモ表示を継続し、完成物にも表示します。

プロフィール、素材、選択媒体、依頼、取り込んだ結果、完成物リンクを永続保存します。再読み込みで消えず、保存失敗時は入力を保持します。本人を信頼できる識別子で固定し、画面とAPIの双方で本人確認します。

## ChatGPTへの依頼と結果

媒体IDは `copy`, `flyer`, `lp`, `x`, `instagram`, `line`, `email`, `checklist` の8つです。選択した媒体だけを依頼します。依頼ごとに新しいrequestIdを発行し、素材の版と対応付けます。

1. 素材と媒体を保存する。
2. 生成指示をコピーしてChatGPTのワークへ渡す。
3. ChatGPTが返したJSONを貼り付ける。
4. 取り込み前の確認画面で内容・注意事項を確認する。
5. 明示的に「取り込む」を押して保存する。

返却形式の例（example-requestは実際の依頼IDに置換）:

```json
{"requestId":"example-request","results":[{"id":"email","text":"ここに告知文","warnings":["開催日時が未定です"]}]}
```

requestId不一致、依頼していない媒体、重複媒体、不正な型、古い素材への返却を検証します。欠けた媒体がある場合は受領分と未受領分を示し、一括完了にしません。文章内のHTMLを実行しません。素材を変更したら既存結果を「更新前の内容」と表示します。

## LP・画像への接続

lpの文章から[制作手順](production-flow.md)に沿って実際の告知LPを作ります。flyerとinstagram等の文章から実際の画像を作ります。ツールは完成物のURLや保存したファイルとの関連を保持し、文章のみ・制作中・完成・確認済みを区別します。

LPの利用URL、チラシ画像、SNS画像を結果と関連付けます。未作成の成果物に架空URLを入れません。完成判定にはLPの表示と申込導線、画像の文字・寸法・表示を含めます。投稿文の完成とSNSへの投稿完了も分けます。

## 完了とやり直し

一度に扱う告知は1件を基本にします。「新しい告知を作る」は現在の内容を消すことを確認し、事業情報は保持します。入力・保存・JSON確認・反映・再読込・完成物参照を通して確認します。
