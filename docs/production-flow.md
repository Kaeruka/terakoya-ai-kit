# 告知文からLP・画像まで作る

## 1. 素材をまとめる

マイツールから事業紹介をコピーし、セミナーまるっと用意くんの事業情報へ保存します。セミナー名、対象者、得られること、日時、会場、料金、申込先を入力します。未定項目は未定のまま進め、公開前の確認事項に残します。

## 2. 告知文を作って保存する

必要な媒体を選択し、生成指示をChatGPTへ渡します。戻ってきたJSONを確認し、対応する依頼へ取り込みます。依頼IDが違うときは無理に書き換えて取り込まず、正しい依頼の結果を取得します。取り込み後、再読み込みして保存を確認します。

## 3. 完成LPを作る

保存したlpの文章をChatGPTのワークに渡し、Sitesで告知LPを作成します。実際の申込先がある場合だけCTAへ設定します。未定の場合は「受付準備中」等で表示し、動かない申込ボタンを設置しません。

使う指示の例:

> この告知文をもとに、スマートフォンで読めるセミナー告知LPをSitesで実際に作成してください。参加対象、得られること、内容、開催情報、申込導線を順に配置してください。未定の情報や実績を創作せず、デモの場合は全画面でデモだと分かるようにしてください。完成後、表示とリンクを確認し、確認用URLを示してください。公開は確認用保存と区別してください。

PC・スマートフォンの表示、日付・料金・申込先、リンク先を確認し、完成URLをツールのlp結果へ記録します。文章の出力やコード提示だけではこの工程は完了しません。

## 4. チラシ・SNS画像を作る

画像生成を使い、保存した告知文から実際の画像を作ります。用途ごとに必要な寸法を指定し、タイトル・日付・場所・参加方法が読めることを確認します。ロゴや写真は使用できる素材だけを渡します。

指示の例:

> この告知文からSNS向けの正方形画像を実際に生成してください。セミナー名を最も大きくし、開催情報と参加方法を読みやすく配置してください。未定項目は創作しないでください。これはデモ素材なので「デモ」と明記してください。画像を確認し、文字の誤りや切れがあれば修正してください。

チラシが必要ならA4縦等の用途も指定します。印刷に使う場合は印刷先の解像度・余白・形式を別途確認します。SNS画像とチラシはそれぞれ表示を確認し、完成ファイルを結果に関連付けます。

## 5. 告知とSNSをつなぐ

公開済みの告知LPをdetailUrl、公開済みの関連SNS投稿をsnsUrlへ設定すると、共通告知から両方を開けます。SNS投稿前はsnsUrlを空文字（""）にします。投稿文や画像の完成は投稿そのものを意味しません。

共通告知は運営が選んだ内容を配信する仕組みです。参加者が作った告知を、自動で全員のマイツールへ掲載しません。

## 6. 操作を記録する

[検証チェックリスト](verification.md)に沿って、操作前・結果・再読込後を必要箇所でキャプチャします。手順書には実際の画面、操作、確認できる結果、つまずいたときの戻り先を記録します。個人情報やアカウント情報を写さず、架空の素材を使います。
