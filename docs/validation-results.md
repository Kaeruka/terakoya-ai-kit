# 初版の実測結果と残る確認

## 確認できた流れ

2026年9月13日、運営者のChatGPT Pro / Work / Sitesで実測しました。架空のセミナー素材を使用し、SNS投稿や募集は行っていません。

- 公開GitHubの共通仕様をWorkが実際に読み、検証用マイツールを1つ作成。
- 事業名の回答前に実装開始。追加指示後は制作中に1問を表示し、事業名・事業内容を同じサイトへ反映。
- セミナーまるっと用意くんをマイツールへ登録。コピーした事業紹介の受け渡し、8媒体の実生成JSONの確認・保存・再読込を確認。
- 異なる依頼IDの返答を画面上で拒否。
- 告知JSONだけを更新し、公開デモと本人限定ツールの2サイトに同じ内容が届くことを確認。配信元のキャッシュで数分待つ場合があり、即時配信ではありません。
- 実際のLPとチラシPNG・SNS用PNGを生成。LPのURLと画像をツールに保存し、再訪して開けることを確認。
- LPと完成URL欄を390px幅で確認。本人以外の別アカウントは検証用マイツールの閲覧を拒否されました。
- 両サイトの型チェック・ビルド、告知4件とプロフィール2件の自動テストが成功。

## 修正したつまずき

最初の指示では約6分質問が出ず、「1問だけ」を合計1問と解釈しました。配布文を「最初のファイル作成直後」「必要な質問は合計2つ、一度に1問」に修正しています。追加指示込みの実測であり、修正版だけを新規会話に渡したときの再現性は次回確認します。

本人限定サイトの共通告知は、同一オリジンの取得に認証Cookieが必要でした。取得部品を修正し、GitHubへのサーバー取得にはCookieを転送しません。事業プロフィールの任意項目を削除しても古い値が残る問題、保存前の完成URL表示、告知取得の競合と期限終了時の表示も修正しました。

## ワークショップ前に残る確認

- 修正版の短い開始文だけで、新規会話から途中補足なしに制作中ヒアリングを再現する。
- 初心者本人のアカウント・想定プランで実施し、待ち時間を含めて2時間内にどこまでできるか測る。運営者Proでの成功を他プランの保証にしない。
- 公開LPや正式SNS投稿を使う場合は、開催条件と公開先を確定してからデモURLを差し替える。
- 印刷物は使用先の解像度・余白・入稿形式を別途確認する。今回のPNG生成は印刷入稿確認ではありません。

キャプチャを含む運営用手順はNotionに保存し、アカウント名が写る画像は公開リポジトリに入れていません。
